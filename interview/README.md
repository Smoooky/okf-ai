# OKF Interview Lab

Короткое адаптивное AJTBD-интервью: один вопрос на экране, до 9 вопросов, около 3 минут. Работает в браузере без сервера, на русском и английском. В конце — необязательный контакт для 20-минутного разговора. Ответы отправляются команде, если настроен адрес отправки; иначе респондент скачивает их файлом.

Публичная версия: https://kokolsk1y.github.io/okf-interview-lab/ (обновляется отдельно, из репозитория автора).

## Сценарии

- Solo developer: контекст AI, решения, результаты.
- AI builder: перенос контекста и работа нескольких агентов.
- Small team: документация, поиск знаний, передача задач.
- Enterprise: актуальность информации, аудит, ответы сотрудников и AI.
- Контрольная ветка: отсутствие подобных ситуаций.
- Завершение при отсутствии конкретного воспоминания.

Express задаёт до 9 вопросов, включая одно уточнение о времени, плюс необязательный контакт. Deep — добровольный дополнительный вопрос. Свободный текст о событии анализируется простыми явными правилами на обоих языках, чтобы не спрашивать повторно о названном времени, действии или способе сохранения. Это не семантический анализ AI и может пропустить нестандартные формулировки.

## Язык

По умолчанию — язык браузера (русский для `ru-*`, иначе английский). Переключатель RU/EN есть на первом экране, язык можно задать ссылкой: `?lang=ru` или `?lang=en`. Ключи вариантов одинаковые в обоих языках, поэтому ответы сравнимы; язык записывается в отчёт (`lang`).

## Куда приходят ответы

Без настройки ответы остаются в браузере респондента (localStorage), а на последнем экране он может скачать их JSON-файлом. Чтобы ответы приходили команде, подключите Google Таблицу — 5 минут:

1. Создайте Google Таблицу, откройте «Расширения → Apps Script» и вставьте:

   ```js
   function doPost(e) {
     const book = SpreadsheetApp.getActiveSpreadsheet();
     const sheet = book.getSheetByName('answers') || book.insertSheet('answers');
     if (sheet.getLastRow() === 0) {
       sheet.appendRow(['received', 'sessionId', 'lang', 'persona', 'situation', 'status', 'contact', 'report']);
     }
     const r = JSON.parse(e.postData.contents);
     sheet.appendRow([new Date(), r.sessionId, r.lang, r.persona, r.situation, r.validationStatus, r.contact || '', JSON.stringify(r)]);
     return ContentService.createTextOutput('ok');
   }
   ```

2. «Развернуть → Новое развёртывание → Веб-приложение», «У кого есть доступ: все». Скопируйте URL.
3. Вставьте URL в `src/config.js` (`SUBMIT_URL`) — или передайте ссылкой: `?submit=<url>`.

Отчёт уходит один раз за сессию, POST с телом `text/plain` (без preflight). Если сервер ответил ошибкой или недоступен, респондент видит это и может скачать файл. Если у адреса нет CORS-заголовков, запрос повторяется без CORS, и статус «отправлено» тогда не гарантирует, что запись дошла.

## Приватность

На первом экране сказано, что ответы получит команда okf-ai и что контакт оставлять не обязательно. В отчёте нет ничего, кроме ответов на вопросы, языка и случайного идентификатора сессии.

## Изменения (22.10.2026)

- Вариант «Другое» больше не ломает опрос: ключ `other` сохраняется отдельно от свободного текста (`text`). Раньше выбор «Другое» в первом вопросе давал пустой экран, который не лечился перезагрузкой. Повреждённый сохранённый прогресс теперь сбрасывается на первый экран.
- Последний шаг — необязательный контакт (Telegram или email) для интервью и материала по context engineering.
- Отправка ответов команде (Google Таблица через Apps Script или любой адрес, принимающий POST).
- Английская версия и переключатель языка.
- Версия формата отчёта — `schemaVersion: 2` (поля `lang`, `contact`, `personaText`, `situationText`, `text` в transcript).
