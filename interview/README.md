# OKF Interview Lab — демонстрационный MVP

Короткое адаптивное AJTBD-интервью для показа команде. Работает в браузере без API-ключей и сервера. Ответы хранятся **только в localStorage этого браузера** и доступны для скачивания в JSON после завершения. Это не хранилище для реальных респондентов: очистка данных браузера удаляет ответы.

Публичное демо: https://okf-interview-lab-demo.kokolsk1y.chatgpt.site — опубликованы только файлы интервью из этой ветки, без остальных материалов репозитория.

## Запуск

Из корня репозитория:

```bash
python -m http.server 8000
```

Откройте `http://localhost:8000/interview/`. Для проверки на телефоне откройте адрес компьютера в той же сети вместо `localhost`.

Автоматические тесты: `cd interview && npm test`. Установка пакетов не нужна.

## Сценарии

- Solo developer: контекст AI, решения, результаты.
- AI builder: перенос контекста и работа нескольких агентов.
- Small team: документация, поиск знаний, передача задач.
- Enterprise: актуальность информации, аудит, ответы сотрудников и AI.
- Контрольная ветка: отсутствие подобных ситуаций.
- Завершение при отсутствии конкретного воспоминания.

Express задаёт до 9 вопросов, включая одно уточнение о времени. Deep — добровольный дополнительный вопрос. Свободный текст о событии анализируется только простыми явными правилами, чтобы не спрашивать повторно о названном времени, действии или способе сохранения. Такая эвристика может пропустить нестандартные формулировки; она не является семантическим анализом AI.

Исследовательская карточка отделяет сообщение о конкретном событии от подтверждения продуктовой гипотезы. Публичной базы ответов и авторизации в демо нет.
