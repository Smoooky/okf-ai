# okf-ai — сдача вайбкодинг-хакатона Школы Замесина (24.10.2026)

**okf-ai показывает, каким инструкциям и знаниям для ИИ-агентов можно верить прямо сейчас, — и предлагает правку, когда код ушёл вперёд.**

Репозиторий: https://github.com/Smoooky/okf-ai, ветка [`okf-ai-mvp`](https://github.com/Smoooky/okf-ai/tree/okf-ai-mvp).

Попробовать на своём репозитории одной командой (нужны Python 3.10+ и Git):

```bash
uvx --from git+https://github.com/Smoooky/okf-ai@okf-ai-mvp okf trust --html report.html
```

## Проблема
ИИ-агенты (Claude Code, Cursor, Codex, Copilot) пишут код по AGENTS.md, CLAUDE.md, правилам Cursor и базе знаний команды. Эти тексты стареют молча: код меняется, раздел, который его описывает, никто не перечитал, и агент уверенно делает по старому. Доверие к знаниям в Confluence и Notion — «кто последний правил?», а у RAG — никакого.

## Что сделали
Открытый CLI `okf` и GitHub Action поверх [Open Knowledge Format v0.2](https://github.com/GoogleCloudPlatform/open-knowledge-format/blob/main/SPEC.md) от Google Cloud:

| Команда | Что делает |
|---|---|
| `okf trust` / `okf verify` | Карта доверия: какие разделы подтверждены после последнего изменения кода, какие перепроверить, где ссылки ведут в никуда; подтверждение раздела одной командой (правки ИИ подтверждает только человек) |
| `okf trust --html` / `okf view` | Карта доверия одной страницей и сайт базы знаний: полоса доверия, «с чего начать», таймлайн «проверено → код изменился», паспорт знания у каждого документа, граф связей; светлая и тёмная тема, работает офлайн |
| `okf fix` | Готовая правка: механическая без ИИ (файл переехал → новый путь) и черновик через ИИ (`--draft`, свой ключ) с проверкой путей; правка помечается «сгенерировано, не подтверждено»; `--pr` открывает pull request `[OKF-Update]` |
| `okf agents-check` / `okf stale` | Страж в PR: битые пути и команды в инструкциях агентов, документы, чей код поменялся |
| `okf notify` | Напоминания в Slack или Teams тем, кто подтверждал теперь устаревшие разделы |
| `okf shadow` | Shadow-тест: находит ли агент по роутеру нужные документы, не опирается ли на устаревшее, отвечает ли на контрольные вопросы |
| Коннекторы | Confluence, Jira, Notion, Slack через общий интерфейс источников: закрытый эпик или изменённая страница помечают документ «перепроверить»; `okf import confluence` / `okf import notion` переносят страницы в базу |
| `okf init` | Каркас: бандл OKF, файл подтверждений, workflow; `--from-agents` собирает знания из существующих AGENTS.md и CLAUDE.md |
| `okf validate` / `okf agents` | Валидатор OKF v0.2 + строгий профиль команды; роутер `AGENTS.md` для ленивой загрузки знаний агентом |
| `okf scan` | Прогон по списку репозиториев — проба спроса |

Всё работает локально, детерминированно, без сервера; сеть — только для ИИ-черновика, коннекторов и напоминаний, если их настроить. Внешние сервисы (модель, Atlassian, Notion, Slack) проверены на моках и сохранённых ответах, без реальных аккаунтов.

## Демо (2 минуты)
См. раздел «Демо» в [README](../../README.md): репозиторий выдуманного сервиса Wheelo с историей за полгода.
1. `okf trust --html report.html` → страница «Можно доверять 9 из 16 разделов: сломано 1, перепроверить 3».
2. PR меняет `src/auth.py` → Action: раздел Auth в AGENTS.md и `auth_flow.md` перепроверить.
3. `okf fix` → правка пути переехавшего скрипта; `okf fix --draft` → черновик раздела Auth.
4. `okf verify` → снова `okf trust`, всё зелёное.
5. Эпик WHL-42 в Jira закрыт после проверки документа → документ «перепроверить» (на фикстурах).
6. `okf shadow` → агент по роутеру находит нужные документы и не опирается на устаревшие (на сохранённых ответах модели).

Плюс `okf view` — сайт базы знаний с графом связей.

## Проба на реальных данных
`okf scan` по 49 публичным репозиториям с AGENTS.md/CLAUDE.md и коммитами за последние 3 месяца, 4,4 минуты ([сводка](../../examples/scan/summary.md)):

| | Доля репозиториев |
|---|---|
| Хотя бы одна находка | **59%** |
| Раздел, чей код менялся после последней правки | **49%** |
| Ссылка на несуществующий файл или скрипт | **35%** |
| И AGENTS.md, и CLAUDE.md одновременно | 37% |

Оговорки: точность автоматических связей ещё размечается вручную (`label.csv`); «код менялся после правки» не значит «раздел неверен»; выборка — открытые проекты, а не платящие команды.
