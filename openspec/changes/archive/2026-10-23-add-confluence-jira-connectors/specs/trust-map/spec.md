## MODIFIED Requirements

### Requirement: Источники единицы знаний OKF
Источниками файла знаний SHALL быть значения `sources[].resource`, которые распознаёт зарегистрированный коннектор: коннектор git (пути от файла и от корня бандла, ссылки GitHub на файлы этого репозитория), коннектор Confluence (страницы) и коннектор Jira (задачи и эпики); описания области с пробелами и URL, которые не распознал ни один коннектор, не считаются источниками и не влияют на уровень; несуществующий файл-источник делает документ «сломано» с сообщением `source "<resource>" does not exist`, переехавший по истории git — «перепроверить», страница Confluence, изменённая после последнего подтверждения, или задача Jira, перешедшая в Done после него, — «перепроверить», а источник со статусом «неизвестно» не делает документ ни «сломано», ни «перепроверить».

#### Scenario: Источник-путь
- GIVEN `knowledge/auth_flow.md` с `resource: ../src/auth.py`, файл существует
- WHEN строится карта
- THEN источник документа — `src/auth.py`

#### Scenario: Нераспознанный URL не источник
- GIVEN `resource: https://wiki.example.com/auth`
- WHEN строится карта
- THEN этот источник не влияет на уровень документа

#### Scenario: Источника нет
- GIVEN `resource: /src/gone.py`, файла нет и он не переименовывался
- WHEN строится карта
- THEN документ «сломано»: `[ERROR] knowledge/x.md: trust: source "/src/gone.py" does not exist`

#### Scenario: Источник переехал
- GIVEN `resource: ../src/config.py`, файл переименован в `src/settings.py` 2026-09-20
- WHEN строится карта
- THEN документ «перепроверить» с сообщением `../src/config.py moved to src/settings.py on 2026-09-20; …`

#### Scenario: Страница Confluence изменена после подтверждения
- GIVEN `knowledge/tariffs.md` подтверждён `human:maria` 2026-09-05, `resource` — страница Confluence `123456`, изменённая 2026-10-20, коннектор настроен
- WHEN запускается `okf trust`
- THEN документ «перепроверить», сообщение называет страницу, дату её изменения 2026-10-20 и последнее подтверждение 2026-09-05 by human:maria

#### Scenario: Страница Confluence не менялась
- GIVEN страница изменена 2026-08-01, документ подтверждён 2026-09-05
- WHEN запускается `okf trust`
- THEN документ «подтверждено»

#### Scenario: Эпик Jira закрыт после подтверждения
- GIVEN `knowledge/billing_service.md` подтверждён 2026-10-05, `resource: jira://BILL-42`, эпик перешёл в Done 2026-10-18
- WHEN запускается `okf trust`
- THEN документ «перепроверить», сообщение называет `BILL-42`, переход в Done 2026-10-18 и последнее подтверждение

#### Scenario: Эпик закрыт до подтверждения
- GIVEN эпик `BILL-42` перешёл в Done 2026-09-01, документ подтверждён 2026-09-05
- WHEN запускается `okf trust`
- THEN из-за `BILL-42` документ не «перепроверить»

#### Scenario: Коннектор не настроен
- GIVEN `resource: confluence://123456`, `OKF_CONFLUENCE_URL` не задан
- WHEN запускается `okf trust`
- THEN уровень документа определяется остальными источниками, а в выводе у документа видна причина `unknown: connector not configured`
- AND в `--json` связь с этим источником имеет статус `unknown`

#### Scenario: Источник недоступен
- GIVEN Confluence отвечает 404 на страницу из `resource`
- WHEN запускается `okf trust`
- THEN документ не «сломано», источник показан как `unknown: not found`, код выхода не меняется
